## 2.0.0

### Added

- `createMapper` factory API with inferred resource and CRUD method types.
- Native `fetch` and `undici` transports selected with required transport constructors.
- `createAxiosMapper`, `createFetchMapper`, and `createUndiciMapper` presets, plus exported `AxiosTransport`, `FetchTransport`, and `UndiciTransport` adapters.
- Full TypeScript source, declarations, ESM/CJS builds, and strict public types.
- Vitest test suite with 100% statement, branch, function, and line coverage.
- Semantic-release automation, CI, npm lockfile, and security documentation.

### Changed

- `supplant` is replaced by `params` for URL path placeholders; `query` is the only source of query-string parameters.
- axios and undici are optional peer dependencies and are loaded lazily.
- A transport adapter is required; there is no implicit axios fallback.
- Dependencies, GitHub Actions, and package metadata are locked to current versions.
- Node 26 is the default development runtime; CI covers Node 18, 20, 22, 24, and 26.
- npm publishing uses GitHub OIDC trusted publishing with provenance; no `NPM_TOKEN` is stored.
- Production bundles are not minified; minification is left to consumers. Source maps and the duplicate CJS declaration body are no longer published.
- Request resolution caches stable configuration, skips unused interceptor work, and uses allocation-light URL, merge, and fetch paths. See `benchmarks/RESULTS.md`.
- Default branch is `main`.
- Author metadata is now Cezar Sampaio.

### Fixed

- Creating a mapper without an `intercept` config no longer throws.
- Invalid configuration now fails immediately with descriptive errors instead of returning a rejected promise from the constructor.
- Header defaults merge correctly and are normalized before transport.
- Prototype-polluting merge keys are ignored and unsafe resource names are rejected.
- CRUD methods now interpolate `{id}` from `params`.

### Removed

- Babel/Jasmine build and test setup.
- `object-merge` dependency.
- Yarn lockfile.
